Orientações para preparar a placa e o NFC

O QR Code incluído abre https://hero.ia.br/Linktree/. Grave esse mesmo endereço na etiqueta NFC como registro de URL (NDEF). O HTML não programa a etiqueta NFC. Para exibir este novo visual nesse endereço, publique este arquivo como index.html na pasta Linktree do seu site. Antes de fabricar a placa, teste o QR impresso com dois celulares e teste a etiqueta NFC. O botão Google abre meu perfil e suas avaliações. Para abrir diretamente o formulário de avaliação, substitua googleReviewUrl pelo link oficial de solicitação de avaliações do Perfil da Empresa no Google.
